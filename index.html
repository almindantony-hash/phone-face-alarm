Phone Camera Face Check

Enroll your face on this phone, then keep this page open while the ESP32 alarm is armed. Face processing happens in the browser; only the recognition status is sent to Blynk. This is a hobby prototype, not a secure access-control system.

Do not share this page or token. Do not publish a copy containing a token. It is kept in memory only and is not saved by this page. Lower is stricter. Start at 0.48; adjust only if it repeatedly rejects you or accepts another person.

Start the camera, then enrol your face.

Blynk V1 = face recognised

Blynk V2 = camera heartbeat

ESP32 configuration needed: virtual pin V1 must update the authorised-face flag and V2 must update its heartbeat time. The ESP32 should trust recognition only while heartbeat is fresh (for example, under 6 seconds old). If camera, internet, or this page stops, it should treat the face as unknown.

The app sends status to the Blynk Cloud over the internet. The ESP32 itself still needs a compatible 2.4 GHz Wi-Fi connection to Blynk. Your phone may use 5G mobile data separately.
